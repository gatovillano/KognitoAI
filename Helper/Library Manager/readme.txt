Library Manager for Kontakt Portable

Main features:

1. Add encoded libraries in batch mode.
2. Two methods of adding libraries: file system search and import of installed libraries from Windows registry.
3. Add unencoded (home-made) library without generating nicnt file.
4. Remove libraries. Of course, only registrations are deleted, library files are not deleted from your PC storage devices.
5. Show/hide libraries in Kontakt browsers.
6. Reordering libraries in classic Kontakt browser.
7. Change library wallpapers.


Do not forget to press 'SAVE' button, otherwise your new library configuration will not take effect.
