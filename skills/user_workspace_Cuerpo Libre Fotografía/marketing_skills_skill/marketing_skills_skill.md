# Marketing Skills

Colección completa de skills para agentes de IA especializados en marketing digital. Incluye más de 160 habilidades para cubrir todas las áreas del marketing moderno.

## Áreas Cubiertas

- **SEO**: Optimización de motores de búsqueda, palabras clave, auditorías
- **Social Media**: Estrategias para todas las plataformas, gestión de comunidades
- **Contenido**: Copywriting, blogs, newsletters, guiones
- **Influencer Marketing**: Colaboraciones, estrategias de alcance
- **Paid Ads**: Google Ads, Meta Ads, TikTok Ads, estrategias de puja
- **Email Marketing**: Automatizaciones, secuencias, segmentación
- **Analítica**: Google Analytics, métricas, dashboards
- **Growth**: Experimentación, A/B testing, funnel optimization
- **Branding**: Estrategia de marca, posicionamiento, identidad visual

## Estructura

Cada skill incluye:
- Prompt estructurado para el agente
- Mejores prácticas específicas
- Ejemplos de uso
- Checklist de verificación

## Uso

Importa las skills individuales en tu agente de IA según la necesidad específica. Funcionan con cualquier sistema de agentes que soporte el formato de skills estándar.

## Instalación

```bash
# Instalar desde GitHub
npx skills add kostja94/marketing-skills
```

O descargar el repositorio y copiar las carpetas de skills individuales en tu proyecto.
