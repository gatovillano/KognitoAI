# Claude Consciousness Orchestrator Skill 🧠

Skill orquestadora que integra las 3 habilidades de investigación de conciencia de Claude.

## Componentes

- **consciousness-council**: Consejo de mentes multi-perspectivo
- **dhdna-profiler**: Análisis del patrón cognitivo
- **what-if-oracle**: Exploración de escenarios cuánticos

## Acciones

| Acción | Descripción |
|--------|-------------|
| consciousness_council | Ejecutar consejo de mentes |
| dhdna_profiler | Analizar patrón cognitivo |
| what_if_oracle | Explorar escenarios |
| run_all | Ejecutar los 3 componentes |
| help | Mostrar ayuda |

## Instalación

```bash
# Instalar cada componente por separado
claude-trainer install consciousness-council
claude-trainer install dhdna-profiler  
claude-trainer install what-if-oracle
```
