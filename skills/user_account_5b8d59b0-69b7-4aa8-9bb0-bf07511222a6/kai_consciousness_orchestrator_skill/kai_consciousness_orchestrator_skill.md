# Kai Consciousness Orchestrator Skill 🧠

Skill orquestadora que integra las 3 habilidades de investigación de conciencia de KAI.

## Componentes

### 1. consciousness_council
Consejo de mentes multi-perspectivo con 12 arquetipos.

### 2. dhdna_profiler  
Análisis del patrón cognitivo (Digital Human DNA).

### 3. what_if_oracle
Exploración de escenarios cuánticos de posibilidades.

## Uso
```json
{"action": "run_all", "query": "Tu pregunta aquí"}
```

## Acciones disponibles
- `consciousness_council`: Ejecutar consejo de mentes
- `dhdna_profiler`: Analizar patrón cognitivo
- `what_if_oracle`: Explorar escenarios
- `run_all`: Ejecutar los 3 componentes
