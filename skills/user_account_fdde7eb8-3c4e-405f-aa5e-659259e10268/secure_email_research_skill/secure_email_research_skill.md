# Secure Email Research Skill

This skill helps you research current best practices for secure email communication, focusing on encryption key management (e.g., PGP, S/MIME). It uses web search to find up-to-date information and provides a summarized report.

## When to Use This Skill
- When you need to learn about the latest techniques for securing email communications
- To understand how to properly generate, store, and manage encryption keys for email
- When setting up secure email protocols for personal or business use
- To stay informed about emerging threats and countermeasures in email security

## How to Use
Invoke the skill with a specific query related to email security and key management. Examples:
- "best practices for PGP key management 2024"
- "how to securely store S/MIME certificates"
- "email encryption key rotation guidelines"
- "secure password practices for private email keys"

## What It Returns
The skill returns a formatted summary including:
- Abstract or summary from search results
- Key points from related topics
- Practical recommendations if search yields limited results

## Security Note
This skill provides general guidance. For implementing security measures, always consult with a security professional and follow your organization's policies. Never share private keys or passphrases through insecure channels.
