# Estructura del Proyecto Kognito

Este documento describe la estructura de directorios y archivos del proyecto Kognito, generado automáticamente por KogniTerm para facilitar la navegación y comprensión del proyecto.

## Contenido Principal

*   **`Dockerfile.core`**: Dockerfile para el servicio principal.
*   **`Dockerfile.core.hybrid`**: Dockerfile para una versión híbrida del servicio principal.
*   **`Dockerfile.core.minimal`**: Dockerfile para una versión mínima del servicio principal.
*   **`Dockerfile.core.simple`**: Dockerfile para una versión simple del servicio principal.
*   **`Dockerfile.frontend`**: Dockerfile para el frontend.
*   **`Dockerfile.telegram`**: Dockerfile para el componente de Telegram.
*   **`Dockerfile.webapp`**: Dockerfile para la aplicación web.
*   **`GEMINI.md`**: Documentación relacionada con Gemini.
*   **`README.md`**: Archivo README principal del proyecto.
*   **`__pycache__/`**: Caché de Python.
*   **`api/`**: Directorio que probablemente contiene la lógica de la API.
*   **`components.json`**: Archivo de configuración de componentes.
*   **`config/`**: Directorio para archivos de configuración.
*   **`core/`**: Directorio que contiene el código principal de la aplicación.
*   **`credentials/`**: Directorio para credenciales (¡manejar con cuidado!).
*   **`docker/`**: Directorio con configuraciones adicionales de Docker.
*   **`docker-compose.yml`**: Archivo de configuración para Docker Compose, define los servicios de la aplicación.
*   **`docs/`**: Directorio para la documentación del proyecto.
*   **`examples/`**: Directorio con ejemplos de uso.
*   **`external_agents/`**: Directorio para agentes externos.
*   **`globals.css`**: Archivo CSS global.
*   **`knowledge_graph/`**: Directorio relacionado con el grafo de conocimiento.
*   **`kogniterm_history.json`**: Historial de KogniTerm.
*   **`llm_context.md`**: Contexto del LLM en formato Markdown.
*   **`llm_context.txt`**: Contexto del LLM en formato de texto.
*   **`logs/`**: Directorio para los archivos de registro (logs).
*   **`media/`**: Directorio para archivos multimedia.
*   **`mi_nueva_herramienta.py`**: Un archivo Python, posiblemente una herramienta personalizada.
*   **`next-env.d.ts`**: Archivo de definición de entorno para Next.js.
*   **`next.config.mjs`**: Archivo de configuración de Next.js.
*   **`nginx.conf`**: Configuración de Nginx.
*   **`node_modules/`**: Módulos de Node.js.
*   **`package-lock.json`**: Bloqueo de paquetes de Node.js.
*   **`package.json`**: Archivo de configuración de paquetes de Node.js.
*   **`postcss.config.js`**: Configuración de PostCSS.
*   **`public/`**: Directorio para archivos estáticos públicos.
*   **`pyrightconfig.json`**: Configuración de Pyright.
*   **`requirements-build.txt`**: Dependencias de Python para la construcción.
*   **`requirements.complete.txt`**: Dependencias completas de Python.
*   **`requirements.minimal.txt`**: Dependencias mínimas de Python.
*   **`requirements.telegram.txt`**: Dependencias de Python para el componente de Telegram.
*   **`requirements.txt`**: Dependencias principales de Python.
*   **`requirements.webapp.txt`**: Dependencias de Python para la aplicación web.
*   **`run_api.py`**: Script para ejecutar la API.
*   **`run_telegram_bot.py`**: Script para ejecutar el bot de Telegram.
*   **`run_telegram_panel.py`**: Script para ejecutar el panel de Telegram.
*   **`scripts/`**: Directorio para scripts auxiliares.
*   **`src/`**: Directorio de código fuente.
*   **`start.sh`**: Script de inicio.
*   **`tailwind.config.ts`**: Configuración de Tailwind CSS.
*   **`telegram_client/`**: Directorio para el cliente de Telegram.
*   **`telegram_panel/`**: Directorio para el panel de Telegram.
*   **`thumbnails/`**: Directorio para miniaturas.
*   **`tmp/`**: Directorio temporal.
*   **`tools/`**: Directorio para herramientas.
*   **`tsconfig.json`**: Configuración de TypeScript.
*   **`utils/`**: Directorio para utilidades.
