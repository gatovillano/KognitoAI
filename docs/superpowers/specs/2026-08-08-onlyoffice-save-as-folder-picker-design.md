# Design Specification: OnlyOffice Save As Folder Picker & Document Conversion in Documents Cloud

**Date**: 2026-08-08  
**Status**: Pending User Review  

---

## 1. Overview
When editing or managing documents in Documentos Cloud (using OnlyOffice), users need the ability to save copies or convert documents (e.g., from Word `.docx` to `.pdf`) directly into a chosen folder in their cloud storage.

This spec details:
1. Intercepting the `onRequestSaveAs` event in OnlyOffice `DocsAPI`.
2. A new Folder Picker Dialog (`SaveAsFolderModal`) in the frontend UI (`src/app/(dashboard)/documents/page.tsx`).
3. Backend endpoints in `api/onlyoffice.py` for downloading/converting files via OnlyOffice `ConvertService.ashx` and storing them as new `Document` records in specified folders.

---

## 2. Frontend Design (`src/app/(dashboard)/documents/page.tsx`)

### A. OnlyOffice Event Listener (`onRequestSaveAs`)
When configuring `window.DocsAPI.DocEditor`:
```javascript
const editorConfig = {
  ...config,
  events: {
    onRequestSaveAs: (event) => {
      // event.data contains: { title, url, fileType }
      handleOpenSaveAsModal({
        sourceUrl: event.data.url,
        title: event.data.title,
        fileType: event.data.fileType,
        docId: editingDoc?.id
      });
    }
  }
};
```

### B. List Action Trigger
In the document row action menu (and selection action bar):
- Add "Guardar como en carpeta..." / "Exportar / Copiar a...".
- Firing this opens the `SaveAsFolderModal` pre-populated with document details.

### C. `SaveAsFolderModal` Component State & UI
- **Fields**:
  - **Filename Input**: User can edit the name (e.g., `Reporte_Final.pdf`).
  - **Format Selector**: `.pdf`, `.docx`, `.xlsx`, `.pptx` (or keep original).
  - **Target Folder Dropdown**: List of `allFolders` + Root ("Inicio (Raíz)").
  - **Workspace Selector**: Optional workspace assignment.
  - **Quick Action**: "Nueva Carpeta" button to create a destination folder on the fly.
- **Actions**:
  - `Guardar`: Calls `POST /api/onlyoffice/save-as-copy`.
  - On Success: Shows a toast message, refreshes document/folder list, and closes modal.

## 3. Backend Design (`api/onlyoffice.py`)

### A. Endpoint `POST /api/onlyoffice/save-as-copy`
**Request Payload (`SaveAsCopyRequest`)**:
```python
class SaveAsCopyRequest(BaseModel):
    source_url: Optional[str] = None       # URL generated by OnlyOffice onRequestSaveAs
    document_id: Optional[str] = None      # ID of existing doc to copy/convert
    filename: str                          # Name for the new document
    folder_id: Optional[str] = None        # Destination folder UUID
    workspace_id: Optional[str] = None     # Destination workspace UUID
    target_extension: str                  # Output extension (e.g., pdf, docx)
```

**Workflow**:
1. Check workspace/folder write permissions for current user.
2. If `source_url` is provided (from OnlyOffice UI event):
   - Backend downloads binary content from `source_url` via `httpx.AsyncClient`.
3. Else if `document_id` is provided:
   - If `target_extension` matches existing extension: create a direct copy of the file on disk.
   - If `target_extension` differs (e.g. `docx` -> `pdf`): call OnlyOffice `ConvertService.ashx` (or local converter) to obtain converted binary.
4. Save binary to user's storage path (`ensure_onlyoffice_account_dir(...)`).
5. Insert new `Document` DB record with `account_id`, `folder_id`, `workspace_id`, `filename`, `extension`, `file_path`, `file_size`.
6. Trigger background text extraction/RAG processing (`process_document_for_rag`).
7. Return new `Document` JSON.

### B. OnlyOffice `ConvertService.ashx` Integration
Helper function `convert_document_via_onlyoffice(...)`:
- Sends JSON payload to OnlyOffice `ConvertService.ashx`:
  ```json
  {
      "async": false,
      "filetype": "docx",
      "key": "<unique_key>",
      "outputtype": "pdf",
      "title": "converted.pdf",
      "url": "<download_url_for_backend>"
  }
  ```
- Receives converted file URL from OnlyOffice Document Server and downloads it.
